# Project 2 Assignment: Dynamic Programs in C

Three C programs built on structures, dynamic memory, pointers and function pointers.

## Projects

| Project | Answers | Sample run |
|---|---|---|
| 1. Dynamic Academic Performance and Risk Analysis Engine | [project1/README.md](project1/README.md) | [project1/sample_run](project1/sample_run) |
| 2. Dynamic Text Mining and Linguistic Pattern Analyzer | [project2/README.md](project2/README.md) | [project2/sample_run](project2/sample_run) |
| 3. Dynamic IoT Event Monitoring and Callback Engine | [project3/README.md](project3/README.md) | [project3/sample_run](project3/sample_run) |

Each project folder has its code, a `README.md` with the written answers, and a `sample_run/` folder with the input and output of a real run.

## Compile and run

```
cd project1
gcc *.c -o academic_risk_engine
./academic_risk_engine

cd ../project2
gcc *.c -o text_analyzer
./text_analyzer

cd ../project3
gcc *.c -o iot_monitor
./iot_monitor
```
